# beta4 — 02.10.2026

**Включает всё из beta3** (отдельного релиза beta3 не было, её изменения — ниже). Главное в beta4 —
**обновление прошивки из LuCI с сохранением настроек**. Проверено на роутере автора: обновление
beta3 → beta4 через Система → Резервная копия / Обновление ПО, настройки, Wi-Fi, Ethernet, VPN,
приложения на диске, возврат своих пакетов, перезагрузка после обновления.

## Новое

- **Обновление из LuCI** (Система → Резервная копия / Обновление ПО, файл `…-sysupgrade.bin`)
  с сохранением настроек. Раньше sysupgrade на разметке QWRT был отключён. Нашлись две причины,
  по которым он не работал:
  - обновление не начиналось: раздел системы держала служебная точка монтирования «ПО на внешнем
    диске», и роутер молча загружал старую систему;
  - образ записывался, но не загружался: sysupgrade по умолчанию создаёт служебный том, и номера
    томов сдвигались, а загрузчик QWRT ищет ядро и систему по номерам.
- **Проверка образа до записи**: образ для BE7000, ядро в формате, который запустит загрузчик QWRT
  (`config@al02-c6`), размер помещается. Проверка повторяется и при «Force upgrade» — образ, с
  которым роутер не загрузится, не запишется. После записи прошивка сверяет записанное с образом
  (sha256) и номера томов.
- **Свои пакеты возвращаются после обновления**: если при обновлении отмечено «Создать список
  текущих установленных пакетов», то пакеты, поставленные сверх прошивки, установятся снова, как
  только появится интернет (`be7000-pkg-restore`). Если какой-то пакет не встал (например, его
  убрали из фида), попытка повторится при следующем подключении.

## Исправлено

- **DNS переставал работать после перезагрузки**, если до восстановления настроек DNS over HTTPS
  (https-dns-proxy) был выключен, а DNS роутера был направлен на него. Восстановление состояния
  служб выключало его, но он запускался снова до перезагрузки, а после неё — уже нет. Теперь
  https-dns-proxy не выключается, пока DNS идёт через него.

## Изменено

- **Новый фид пакетов** `be7000-qwrt-beta4`. Ядро то же, что в beta3, драйверы из фида beta3 к
  beta4 подходят, но прошивка подключает свой фид.
- **С beta3 и более ранних на beta4 — только через recovery** (в них sysupgrade отключён). Дальше
  обновления — из LuCI.

# beta3 — 02.10.2026

Главное — аппаратная разгрузка NAT через блок PPE процессора и исправления по итогам сверки с
Beam WRT 1.4.0 и Quarx2k. Проверено на роутере автора: установка через recovery, восстановление
настроек, Wi-Fi, Ethernet, IPv4/IPv6, VPN с разгрузкой, приложения на диске, каталог, драйверы из
нового фида, все страницы LuCI с нажатием кнопок.

## Новое

- **Аппаратная разгрузка NAT (PPE)** — Сеть → Аппаратная разгрузка. Работает через штатный
  flowtable OpenWrt, без закрытой прошивки NSS: серия OpenWrt PR #24178 (hurrian) и исправления
  Beam WRT `0905`–`0907`. **По умолчанию выключена** (включается одной кнопкой). На роутере автора
  маршрутизацию и NAT соединений IPv4 и IPv6 делает PPE, в том числе для клиентов Wi-Fi; VPN по
  правилам (pbr) с разгрузкой работает. Нагрузка на процессор для Wi-Fi-клиентов почти не меняется:
  отдача в драйвер Wi-Fi всё равно идёт через процессор. Выигрыш на проводе не измерен.
- **Режимы 5 ГГц из Beam WRT: «два радио» (5G-1/5G-2) и MLO — экспериментально, на железе не
  проверены.** По умолчанию — одно радио 5 ГГц на все четыре антенны, как раньше.
- Ядро: исправления тактирования QCA8084 от Quarx2k (`9511`, `9518`) и передача статуса линка PHY
  (`0374`); резервирование памяти TrustZone как в стоковой прошивке (Beam `011`).
- Приём Ethernet больше не сводится на одно ядро процессора (`packet-steering.sh` из Beam).
- Журнал загрузки сохраняется во флеш (`be7000-bootlog`, из Beam) — пригодится, если роутер не
  загрузится. Пустой `board.json` восстанавливается при загрузке.

## Исправлено

- «ПО на внешнем диске»: кнопки «Старт», «Стоп», «Установить», «Удалить» и «Автозапуск» не
  срабатывали.
- «Стоп» мог ждать 15 с и показывать «работает» у уже остановленной программы, если в системе был
  процесс с её именем в командной строке (например, `grep` или `tail`).
- Каталог: установка во флеш падала с ошибкой 404 (`wget error 8`), если списки пакетов были скачаны
  больше пары часов назад, — фиды OpenWrt пересобираются несколько раз в сутки. Теперь списки
  обновляются перед каждой установкой.
- Каталог, приложения Entware:
  - **File Browser** не запускался (порт 8080 занят qBittorrent) и показывал /opt вместо диска.
    Теперь порт 8088, корень — USB-диск, пароль admin выводится в лог установки.
  - **Syncthing**: веб-интерфейс открывался только на самом роутере, база писалась во флеш. Теперь
    http://192.168.1.1:8384 из сети, данные на диске.
  - **v2rayA** не запускался (ошибка в init-скрипте пакета Entware).
  - Эти исправления применяются заново при каждом запуске Entware — `opkg upgrade` их не сотрёт.
- Каталог и «ПО на внешнем диске» больше не запускают установки одновременно.
- Форматирование диска: если процесс форматирования аварийно завершился, страница больше не ждёт
  бесконечно.

## Изменено

- Ядро новое → **новый фид драйверов** `be7000-qwrt-beta3`. Модули из фида beta2 к beta3 не
  подходят (и наоборот); прошивка подключает свой фид сама.
- Убраны патчи ядра для ускорения NSS (`0910`–`0917`): без прошивки NSS они не работали и
  конфликтовали с разгрузкой PPE.
- sysupgrade на разметке QWRT по-прежнему отключён — обновление через recovery.

# beta2 — 02.10.2026

Прошивка перенесена на свежий OpenWrt (main от 01.10.2026). Проверено на роутере автора:
установка через recovery, восстановление настроек, Wi-Fi, Ethernet, VPN, приложения на диске,
каталог, все страницы LuCI.

## Обновлено

- **Ядро 6.18.54** (было 6.18.36) — самый свежий longterm-выпуск.
- **Драйверы Wi-Fi из ядра 7.2** (backports 7.2, было 6.18). Патчи поддержки BE7000 перенесены
  на новые драйверы. Скорость на телефоне — 1062/1138 Мбит/с (упор в провайдера).
- Все пакеты и LuCI — по состоянию фидов OpenWrt на 01.10.2026.

## Новое

- **Каталог приложений** (Службы → Каталог приложений): около 50 программ по категориям, установка и
  удаление одной кнопкой — во флеш, на USB-диск или в Entware на диске. Показывает свободное место
  и живой лог установки. Полный список (~7 500 программ) остался в Система → Программное обеспечение.
- **Entware** на USB-диске (~3000 пакетов): AdGuard Home, Syncthing, File Browser, rclone, v2rayA,
  Python, Node.js. Ставится сам при первой установке такого приложения.
- **Драйверы (kmod) под ядро прошивки** — в фиде на GitHub (USB-модемы 4G/5G, интернет с телефона по
  USB, принтеры, NFS, MultiWAN и др., ~930 модулей). Фид подключается сам; официальный target-фид
  OpenWrt отключён — его модули собраны под другое ядро и не ставились.
- **zapret** (обход DPI, со страницей в LuCI) — выключен по умолчанию.
- **DNS over HTTPS** (https-dns-proxy) — выключен по умолчанию.
- **watchcat** (перезагрузка при пропаже интернета), **vnStat** (история трафика, хранится во флеше),
  **графики** (collectd), **banIP** (выключен).
- **Форматирование USB-диска в ext4** из LuCI (с подтверждением). На ext4 приложения ставятся прямо
  на диск, без файла-образа.
- Списки пакетов скачиваются сами при подключении к интернету (раньше в «Программном обеспечении»
  было видно только установленное).

## Исправлено

- Страница «ПО на внешнем диске»: при сбое связи с роутером кнопки бесконечно крутились, а лог был
  пустым. Теперь ошибка показывается, а кнопки видны только нужные (установлено → «Стоп/Удалить»,
  не установлено → «Установить»).
- banIP больше не пишет ошибку в журнал при каждой загрузке, пока выключен.

## Изменено

- **MiniDLNA** убран из прошивки в каталог: новый ffmpeg занимает ~15 МБ. У кого был включён —
  поставьте из каталога (Файлы → MiniDLNA), настройки сохранятся.
- sing-box собран без встроенного Tailscale (Podkop его не использует; Tailscale ставится на диск).

## Известное

- Не собраны (в прошивку не входили и раньше): экспериментальное NSS-ускорение (qca-nss-ecm/clients,
  qca-mcs), rtpengine.
- Эффективность zapret/Podkop против блокировок российских провайдеров автор проверить не может.
- Форматирование диска в ext4 на реальном диске ещё не проверено.
