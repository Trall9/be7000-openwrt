# OpenWrt для Xiaomi BE7000 (QWRT-разметка, раздел 80 МБ)

Сборка OpenWrt для **Xiaomi BE7000 (RC06, IPQ9574 + QCN9274)** под разметку
**QWRT-загрузчика** (один раздел `rootfs` 80 МБ). За счёт большого раздела в
прошивку помещается всё нужное сразу: VPN, обход блокировок, samba, DLNA,
**каталог приложений** с установкой в один клик.

> ⚠️ **Бета для тестирования.** Образ — в [Releases](../../releases). Ставьте, если готовы
> при неудаче вернуться на QWRT через recovery. Что изменилось — в
> [CHANGELOG](CHANGELOG.md).

Основа — порт поддержки BE7000 от [kravasuper](https://github.com/kravasuper/openwrt)
(ветка `xiaomi_be7000`), перенесённый на свежий OpenWrt main, с фиксами Ethernet из
[Beam WRT](https://github.com/timofey-maykov/be7000-openwrt) (timofey-maykov) и находками
[Quarx2k](https://github.com/Quarx2k/OpenWRT-BE7000). **Полный список авторов — что у кого
взято и что доработано здесь — в [CREDITS.md](CREDITS.md).**

## Разметка QWRT 80 МБ: что она даёт и чего стоит

Стоковый загрузчик Xiaomi делит флеш на два слота по 40 МБ (A/B), загрузчик QWRT отдаёт системе
один раздел 80 МБ.

**Что даёт:** в саму прошивку помещается больше встроенного софта — образ этой сборки 53 МБ и в
стоковый слот не влезет (sing-box для Podkop, zapret, samba, графики, каталог). Свободного места
под пакеты при этом примерно столько же, сколько у сборок на стоковой разметке (~20 МБ).

**Чего стоит:**
- нет второго слота: если обновление не загрузится, автоматического отката нет — только recovery
  загрузчика (он не стирается, но нужен ПК с кабелем);
- обновление с beta4 — из LuCI (Система → Резервная копия / Обновление ПО) с сохранением
  настроек, но перезаписывается единственный раздел: если новый образ не загрузится, вернуть
  роутер можно только через recovery (перед записью прошивка проверяет образ, чтобы этого не
  случилось);
- чтобы поставить, нужен загрузчик QWRT; вернуться на сток сложнее, чем со сборок с A/B-слотами.

Если вам важнее простые обновления и сток в запасном слоте — берите
[Beam WRT](https://github.com/timofey-maykov/be7000-openwrt).

## Недостатки и ограничения beta4

- **Обновление из LuCI появилось в beta4.** С beta3 и более ранних на beta4 — только через
  recovery (в старых образах sysupgrade отключён); дальше — из LuCI. Обновление проверено на
  одном роутере (beta3 → beta3, beta3 → beta4). Новой версии прошивка сама не ищет: образ
  `…-sysupgrade.bin` скачивается из Releases вручную (в Beam WRT поиск и установка в одну кнопку).
- **Режимы 5 ГГц «два радио» (5G-1/5G-2) и MLO** взяты из Beam WRT, но на железе автора **не
  проверены** — экспериментально. По умолчанию одно радио 5 ГГц.
- **Аппаратная разгрузка NAT (PPE)** — новая, **по умолчанию выключена**. Проверена на одном
  роутере с Wi-Fi-клиентами, IPv4/IPv6 и VPN по правилам; выигрыш на проводе не измерен,
  разгрузка моста LAN-портов не проверялась.
- **Extroot (перенос /overlay на USB) — новый в beta4**, проверен на одном роутере и одном диске
  (NVMe в USB-боксе): перенос, перезагрузки, обновление из LuCI с extroot, имитация отвала диска.
  Один раз при тестах корень на диске перестал читаться через минуту после загрузки (сеть
  работала, SSH и LuCI — нет); причину установить не удалось, повторить за пять загрузок не
  вышло. На этот случай есть сторож: он перезагружает роутер, а при повторе возвращает его на флеш.
- **Нет импорта настроек со стока** (есть в Beam WRT).
- Проверено **на одном роутере** автора. Эффективность zapret/Podkop против блокировок российских
  провайдеров не проверена; форматирование диска в ext4 на реальном диске не проверено.
- Ускорение NSS (qca-nss-ecm и др.) не используется: для IPQ9574 нет открытой прошивки NSS,
  разгрузка сделана через PPE.

## Что внутри

- **Wi-Fi:** 2.4 ГГц (ath11k, Wi-Fi 6) + 5 ГГц (ath12k QCN9274, Wi-Fi 7, до 160 МГц), 802.11k/v, WPA3.
- **VPN:** WireGuard, **AmneziaWG** (пакеты YAAWG 3.1.2; протокол AWG 2.0 — I1–I5, диапазоны H, конфиги старого формата без I1 тоже работают), OpenVPN. Страница **VPN → Быстрая настройка**:
  вставить `.conf` или ключ `vpn://` из AmneziaVPN → «только выбранные сайты» или «весь трафик».
- **Обход блокировок** (выключены по умолчанию): **zapret**, **Podkop** (sing-box: VLESS/Reality,
  Trojan, Shadowsocks, Hysteria2), byedpi, pbr, **DNS over HTTPS**.
- **Аппаратная разгрузка NAT (PPE)** — Сеть → Аппаратная разгрузка (по умолчанию выключена).
- **Сеть:** SQM, UPnP, DDNS, adblock-fast, nlbwmon, vnStat, графики (collectd), watchcat, banIP, IPv6
  (сам включает relay + NAT66, если провайдер не выдаёт префикс).
- **Диск:** samba4 + wsdd2, minidlna, NTFS/exFAT/ext4, автомонтирование, **форматирование USB-диска
  в ext4 из LuCI**.
- **Extroot** — Система → Оверлей на USB-диске: /overlay (настройки и пакеты) переезжает на раздел
  ext4 USB-диска. Подробнее — ниже.
- **Каталог приложений** (Службы → Каталог приложений): ~50 избранных программ по категориям,
  установка и удаление одной кнопкой:
  - во **флеш** роутера — из фидов OpenWrt (с русским переводом LuCI);
  - на **USB-диск** — qBittorrent, Xray, Tailscale, Docker, Jackett;
  - в **Entware** на USB-диске (~3000 пакетов) — AdGuard Home, Syncthing, File Browser, rclone,
    v2rayA, Python, Node.js…
  - **драйверы** (USB-модемы 4G/5G, интернет с телефона по USB, принтеры, NFS, MultiWAN) — из
    фида этой прошивки (все ~930 kmod собраны под её ядро).
- Полный список (~7 500 программ, 11 000+ пакетов с переводами LuCI) — как обычно, Система → Программное обеспечение
  (списки пакетов скачиваются сами при подключении к интернету).
- LuCI на русском.

## Установка (с QWRT)

Нужно: ПК с кабелем в LAN-порт, файл `…-squashfs-factory.ubi` из Releases.

1. Убедитесь, что у вас QWRT-загрузчик и раздел `rootfs` 80 МБ (`cat /proc/mtd`).
2. Сохраните настройки, если нужны (Система → Резервное копирование → «Создать архив»).
3. ПК: статический адрес `192.168.1.10 / 255.255.255.0`.
4. Роутер: питание OFF → зажать **Reset** → питание ON → держать 10–15 с (мигает оранжевым) → отпустить.
5. Браузер: `http://192.168.1.1` → **FIRMWARE UPDATE** → `…-factory.ubi`. Ждать 3–5 мин.
6. ПК вернуть на DHCP. LuCI: `http://192.168.1.1`, пароль root пустой — задайте сразу.
   Wi-Fi: `BE7000` / `BE7000_5G`, пароль `be7000setup` — смените.

Если после заливки роутер долго (> 5 мин) мигает оранжевым и не загружается — повторите
recovery: он живёт в загрузчике и не стирается. Известная причина «стёрлось, но не записалось» —
переменная загрузчика `loadaddr=0x0`; лечится в консоли загрузчика (UART):
`setenv loadaddr 0x50000000; saveenv`. `fw_printenv` из системы на QWRT-разметке может показывать
не то окружение, которым пользуется загрузчик — не ориентируйтесь на него.

## Обновление

**С beta4 и новее** — из LuCI, с сохранением настроек:

1. Скачайте из Releases `…-squashfs-sysupgrade.bin` (не `factory.ubi`).
2. **Система → Резервная копия / Обновление ПО** → «Прошить образ…» → выберите файл.
3. Сверьте SHA-256 с `sha256sums.txt` релиза. Отметьте «Сохранить настройки» и «Создать список
   текущих установленных пакетов» — тогда пакеты, которые вы ставили сами, установятся снова,
   как только появится интернет. «Force upgrade» не нужен.
4. «Продолжить» — роутер перезагрузится через 3–4 минуты. Питание не выключать.

Перед записью прошивка проверяет образ (что это образ для BE7000, что загрузчик QWRT сможет его
запустить, что он помещается) и отказывает, ничего не стерев; проверка работает и с «Force
upgrade». После записи сверяет записанное с образом. Второго слота нет: если обновлённая система
не загрузится (ровный оранжевый светодиод), помогает только recovery, как при установке.

**С beta3 и более ранних** — только через recovery, как при установке (в этих образах sysupgrade
отключён). Настройки сохраните заранее и восстановите после.

Откат на QWRT — recovery с QWRT `…-nand-factory.bin`.

## Extroot: /overlay на USB-диске

Во флеше под настройки и пакеты ~20 МБ. Система → **Оверлей на USB-диске** переносит /overlay на
раздел USB-диска, и места становится столько, сколько на разделе. То же из консоли:

```
be7000-extroot list                     # разделы и почему какой-то нельзя взять
be7000-extroot use /dev/sda3 --yes      # форматировать в ext4 и перенести
be7000-extroot use /dev/sda3 --keep     # перенести на готовый ext4 без форматирования
be7000-extroot status
be7000-extroot revert --yes --reboot    # вернуть во флеш (настройки скопируются)
```

- **Нужен раздел ext4 от 256 МБ.** NTFS/exFAT/FAT не подходят — на них нет прав доступа Linux.
  Диск с данными форматировать не нужно: создайте рядом отдельный раздел (например, в «Управлении
  дисками» Windows) и выберите его. Смонтированные разделы и разделы меньше 256 МБ страница не
  предлагает.
- **Обновление из LuCI работает.** Диск привязан к сборке прошивки: новая версия при первой
  загрузке встаёт на флеш с перенесёнными настройками, переносит их на диск (старое содержимое —
  в `upper.prev`), перезагружается, а поставленные вами пакеты возвращаются, когда появится
  интернет. Старые пакеты и модули ядра с диска на новую прошивку не попадают.
- **Если диск не подключился при загрузке** — роутер работает с флеша, с настройками на момент
  переноса; страница это показывает.
- **Если диск отвалился во время работы** (сбой USB, отошёл кабель), система на нём перестаёт
  читаться. Сторож замечает это за 15 с и перезагружает роутер; если диск пропадёт второй раз за
  10 минут после загрузки — выключает extroot, и роутер встаёт на флеш.
- Не отключайте диск от работающего роутера, пока /overlay на нём.

## Фид пакетов

Прошивка сама подключает `https://trall9.github.io/be7000-openwrt/<версия>/` — драйверы (kmod)
под её ядро и пакеты сборки (zapret, podkop, amneziawg, byedpi…). Пакеты подписаны ключом
сборки; ключ встроен в прошивку. Официальный target-фид OpenWrt отключён: его kmod собраны
под другое ядро и не устанавливаются.

## Сборка из исходников

```sh
git clone https://github.com/Trall9/be7000-openwrt.git
cd be7000-openwrt
./build.sh ~/openwrt-be7000 $(nproc)
```

`source/patches/` — изменения поверх OpenWrt (`git am`), `source/files/` — файлы прошивки,
`source/diffconfig` — конфиг, `source/feeds.lock` — коммиты OpenWrt и фидов.
Своя сборка подписывает пакеты своим ключом — фид этого репозитория она не примет
(собирайте и свой фид: `bin/targets/…/packages`).
